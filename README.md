## 🚀 TaskFlow — Productivity & Task Management App
«Plan. Focus. Complete. 🎯»

TaskFlow is a modern, responsive task manager built with plain HTML, CSS and vanilla JavaScript. It has no build step, no framework and no backend — every task lives in your browser's localStorage, so the app works offline and stays instant.

---

## ✨ Features

📊 Dashboard

- 📌 Total tasks overview
- ⏳ Pending tasks
- ✅ Completed tasks
- 📈 Progress tracking
- 📋 Today's tasks
- ⚡ Quick task creation

📝 Task Management

- ➕ Create new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as completed
- 📌 Pin important tasks
- 🔎 Search tasks
- 🎯 Set task priorities
- 🏷️ Organize tasks by categories
- 📅 Set due dates

🔍 Filtering & Sorting

Filter tasks by:

- 📌 Status
- 🏷️ Category
- 🎯 Priority
- 📅 Due date

Sort by:

- 🆕 Newest
- 🕐 Oldest
- 🚨 Priority
- 📅 Due date
- 🔤 Alphabetical order

📈 Analytics

TaskFlow provides productivity insights including:

- 📊 Tasks by category
- 🎯 Tasks by priority
- 📈 Productivity statistics
- ✅ Completion tracking
- 🔢 Task metrics

⚙️ Settings

- 🌞 Light theme
- 🌙 Dark theme
- 🖥️ System theme
- 🎨 Custom accent color
- 💾 Local browser storage
- 📥 Export data as JSON
- 📤 Import data from JSON
- 🗑️ Reset all data

📱 Responsive Design

TaskFlow is designed to work across:

- 💻 Desktop
- 💻 Laptop
- 📱 Mobile
- 📲 Tablet

The sidebar automatically adapts for smaller screens. 📐📱

| Shortcut | Action |
| --- | --- |
| `Ctrl` / `⌘` + `K` | Focus search |
| `Ctrl` / `⌘` + `N` | New task |
| `Esc` | Close dialog |

## 🧠 Architecture

TaskFlow uses a simple modular Vanilla JavaScript architecture:

TaskFlow
│
├── 🎨 UI Layer
│   ├── Dashboard
│   ├── Tasks
│   ├── Completed
│   ├── Analytics
│   └── Settings
│
├── 🧠 Application Logic
│   ├── Task Service
│   ├── Analytics
│   └── UI Controller
│
└── 💾 Data Layer
    └── LocalStorage

The application stores task data in the browser using "localStorage", allowing tasks to remain available after refreshing the page.

---

## 💾 Data Management

TaskFlow currently uses browser LocalStorage for its MVP data layer. Users can:

- 💾 Save tasks locally
- 📥 Export tasks as JSON
- 📤 Import previously exported JSON
- 🗑️ Reset all stored data
